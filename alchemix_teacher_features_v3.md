# Alchemix: Educator Instructional & Evaluation Features

This document outlines the specific management, configuration, and evaluation tools available to Chemistry Educators within the Alchemix platform.

## 1. Class Onboarding & Student Management
* **Unique Class Join Codes:** Educators can create specific class sections (e.g., "Grade 10 - Mendeleev") which automatically generate a unique 6-character alphanumeric code or shareable link.
* **Seamless Enrollment:** Students input this join code on their dashboards to automatically populate the educator's digital roster.
* **Credential & Access Oversight:** Allows educators to manage student profiles, monitor active lab sessions, and reset credentials directly within their assigned chemistry classes.

## 2. Interactive Chemistry Quiz Builder
* **3D Mix-and-Match Bonding Setup:** Allows teachers to select specific elements and define target compounds (e.g., NaCl or H2O). Teachers can configure the 3D bonding workspace rules where students must correctly match valency electrons to pass.
* **Equation Balancing Configurator:** Enables educators to input unbalanced chemical equations (e.g., combustion or synthesis reactions) and set specific time limits for the students' "Time-Attack" stoichiometry quizzes.
* **3D Visual Identification Tasks:** Teachers can spawn specific 3D molecular structures or isotopes into a quiz format and create prompts requiring students to identify the element, bond type, or atomic mass.

## 3. Curriculum & Chemistry Mission Configuration
* **Custom AR Scavenger Hunt Builder:** Allows teachers to configure or select specific chemistry problem sets, equation balancing tasks, and AR card prompts aligned with current lesson plans.
* **Simulation Parameter Adjustments:** Grants teachers the ability to unlock, restrict, or modify specific simulation modules (e.g., locking the Gas Laws simulator until the class passes the Atomic Structure module).

## 4. AI-Assisted Evaluation & Analytics Dashboard
* **AI Evaluation Review Logs (Pre-Grading Audit):** The system's multimodal AI automatically pre-grades AR submissions and Time-Attack quizzes. Teachers use this interface to review captured base64 AR frames and handwritten student solutions.
* **Manual Score Override:** Instructors retain full authority to override the AI's automated scoring (e.g., granting points if a student's handwriting was misread but the chemistry logic is correct).
* **Real-Time Class Performance Matrix:** Once grades are approved, they automatically populate a centralized grid aggregating class-wide accuracy data for atomic building, equation balancing, and scavenger hunts.
* **High-Error Concept Identification:** Automatically flags specific chemistry topics or molecular equations where the class exhibits high error rates, helping educators pinpoint concepts requiring targeted review sessions.
