# Glossary of Invented Vocabulary (Manuscript Appendix)

> Adviser item 16: the manuscript needs an appendix listing every invented
> word with its meaning. This file is the canonical word list — it mirrors
> `GLOSSARY` in `src/lib/lexicon.ts` (shown in-app at /lexicon). Per her
> sequencing instruction, write the full USER MANUAL only once the platform
> is final; this word list is prepared now.

| Term | Meaning |
|---|---|
| The Alchemist | The platform's mentor character. Answers questions, gives warm counsel on mistakes, and narrates the modules. |
| Apprentice | A student. Every learner in AlcheMix is an apprentice of the Alchemist. |
| Grimoire | The student's card collection — the book of element cards collected and forged. Also names the platform's fantasy frame as a whole. |
| Forge / Forging | Combining two element cards to make a real chemical compound. Runs on actual valence rules. |
| Codex | The compound encyclopedia. Every compound forged earns a page there. |
| Trial | A module's challenge mode. Scores earn stars kept as personal bests — motivation, never grades. |
| Aurum | The practice currency earned from activities (Latin for gold). Spent on cosmetics in the Emporium; it is not a grade. |
| The Emporium | The shop where aurum buys cosmetic frames, titles and charms. |
| The Study | The guided lesson module: five topics, each learned, practised and assessed in sequence. |
| Daily Starters | The daily three-question warm-up rite, with streaks kept in a cauldron. |
| The Mending Trial | The quiz that restores a lapsed Daily-Starters streak — a broken streak must be earned back. |
| The Bench | The student home page (dashboard), where the day's work is laid out. |
| The Astrolabe | The educator console — classes, gradebook, quiz builder and performance views. |
| The Alembic & The Phial | Daily drop vessels on module pages: one tap a day adds a drop toward a small surprise. |
| Itsura | A card's cosmetic appearance/frame, equipped from the Emporium. |
| Hall of Records | The class leaderboard (stars, duels, compounds, streaks). |
| Assayer's Lens | The phone camera mode that identifies the elements inside everyday objects. |

When adding a new invented word to the platform, add it to BOTH
`src/lib/lexicon.ts` (GLOSSARY) and this table in the same commit.
