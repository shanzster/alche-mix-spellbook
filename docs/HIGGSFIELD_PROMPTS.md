## 0 · Shared style (paste this into EVERY prompt)

Keep every image in one visual language so the page reads as a single engraved
book, not a collage. Prepend this block to each section prompt below:

> **Style:** antique engraved ink illustration, 18th-century alchemical manuscript
> plate, fine cross-hatching and stipple linework, aged parchment and deep
> midnight-blue ground, antique gold filigree accents, a faint teal arcane glow,
> subtle gold-dust and ink-stain grain. Muted, desaturated, candle-lit. No modern
> elements. Painterly but restrained — ornament at the edges, calm in the centre.

> **Palette:** parchment `#f6f3ec`, antique gold `#e0b457`, teal `#2dd4bf`
> (sparingly, as glow only), violet `#8b5cf6` (faint), midnight ground near-black.

> **Negative / avoid:** text, letters, numbers, watermarks, logos, UI, people's
> faces in focus, bright saturated colours, neon, photographic realism, lens
> flare, 3D-render look, cluttered centre, high contrast across the middle third.

### Composition rule — leave room for the words
Each background sits *under* headlines and body copy. **The centre must stay
dark, quiet, and low-contrast** so white/parchment text stays legible; push all
detail, ornament, and focal interest to the **edges and corners**. Think
"vignette with a calm hole in the middle."

### Technical specs (all files)
- **Format:** WebP (and keep a PNG master).
- **Dimensions:** 1792 × 1024 landscape for section bands; **1536 × 1920 portrait**
  for the hero (it goes full-bleed on mobile too).
- **Save to:** `public/backdrops/` using the filenames below.
- **Weight:** aim ≤ 350 KB per WebP — these are backdrops, not hero art.
- **Theme:** the landing runs dark, so these are the dark masters. Optional:
  generate a lighter "parchment-day" variant of each (swap midnight ground for
  aged-paper cream) if we later theme the landing light — mirrors the existing
  `night-ink` / `parchment-day` pair.
