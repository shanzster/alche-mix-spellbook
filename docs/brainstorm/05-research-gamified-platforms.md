# Research — Gamified Chemistry Platforms & Games

Feature research for the AlcheMix brainstorm. Compiled 2026-09-02.
Covers Collisions, Legends of Learning, Little Alchemy/Doodle God, ChemCaper & chemistry
card/board games, Kahoot/Blooket/Gimkit, BrainPOP/Toca/Tinybop, Minecraft Education Chemistry.

## Collisions by Playmada Games (k12.playmada.com)

- **What it is:** 8 interconnected digital chemistry games "grounded in the rules of chemistry": Atoms, Ions, Covalent Bonding, Ionic Bonding, Intermolecular Forces, Acids & Bases, Phase Change, Equilibrium. Web + tablets; HS and Higher-Ed versions.
- **Core loop:** each game has three layers — Tutorial Levels (teach the mechanic), Game Levels (leveled challenges of increasing difficulty), and an exploratory Sandbox. Loop = read target → drag/manipulate particles → the system enforces real chemistry rules → level cleared → harder target.
- **Chemistry → mechanics, per game:**
  - Atoms: build atoms by placing protons in the nucleus and electrons in orbitals, discovering Aufbau fill order through play.
  - Ions: add/remove electrons while monitoring ionization energies — the game "pushes back" when you try to remove core electrons.
  - Covalent Bonding: build molecules with target geometries; electronegativity drives visualized bond polarity.
  - Ionic Bonding: build compounds to target ratios with monatomic and polyatomic ions (charge balance = win condition).
  - IMFs: create LDFs, dipole-dipoles, hydrogen bonds by arranging molecules.
  - Acids & Bases: add/remove protons to hit target species; strong vs weak behavior is a mechanic.
  - Phase Change: add/remove energy to hit target phase sequences; particle motion and IMF breaking/forming are the simulation.
  - Games interconnect: species built in earlier games are the building blocks of later ones.
- **Progression:** leveled challenges; Sandbox has assignable "Sandbox Achievements"; Sandbox doubles as a data-collection lab ("collect data in-game, analyze it to derive a concept").
- **Multiplayer:** none — single-player mastery.
- **Teacher features (strong suit):** Teacher Portal with real-time progress per level and per sandbox achievement; assign specific levels (early levels pre-instruction, later post-instruction), Sandbox Achievements, Student Quests, Checks for Understanding, lab activities; Google Classroom, Clever SSO; Quick Start + full Game Guides per game.
- **Worth stealing:** rules-enforced sandbox where the chemistry engine IS the feedback; tutorial→levels→sandbox triad; collect-data-then-analyze pattern; assigning individual levels as pre/post-instruction chunks; target-based building as the win condition.

## Legends of Learning

- **What it is:** marketplace of 2,000+ short curriculum games (K-8 science + math), NGSS-aligned, 7–10 games per learning objective (Chemical Reactions, Atoms & Elements, Molecules & Compounds, Periodic Table, Bonding…). Genres: puzzle, adventure, simulation, strategy, plus sims and assessment items.
- **Platform loop:** teacher builds a playlist (instructional game → simulation → formative assessment) → students play through it → embedded questions interleave with gameplay → real-time data to teacher. Games are 5–25 min disposable experiences; durable progression lives in the platform meta-layer.
- **Meta-progression ("Awakening"):** persistent Pokémon-like home world. Coins earned from academic play buy avatar clothing, dance moves, furniture; collect and battle "Beasties." Earn-in-class, spend-in-world separation.
- **Multiplayer:** Beastie battles vs other players; shared world; live in-class sessions with the whole class on one playlist.
- **Teacher features:** free tier; pick a standard → curated game list → assign playlist; custom playlists mixing games/sims/question sets; real-time granular analytics (which concepts a student missed, time-on-game, score vs class average); vetted content with teacher ratings.
- **Worth stealing:** playlist model; many small games per objective; academic-play-earns / reward-play-spends separation; per-concept misconception analytics.

## Little Alchemy 2 / Doodle God (combination-discovery genre)

- **Little Alchemy 2 loop:** start with 4 basics (air, earth, fire, water); drag any two items together; valid pair → new item in a growing **encyclopedia** (720 items). No fail state — pure exploratory curiosity. Item types: basic, craftable, milestone-gated unlockables, and terminal/"final" items (dead ends, marked so you stop trying). Encyclopedia entries carry witty descriptions — the collection is the reward. Metered hint system (one recipe hint at a time). Player heuristics: "mix an item with itself," "hub items lead to many discoveries."
- **Doodle God additions:** ~250 elements in 26 category groups with visible progress bars; Episodes (content unlocks in chapters so the combination space never overwhelms); Quests (scenario puzzle paths); Puzzle Mode (build a specific target artifact); Artifacts (rare triple-combinations yield collectibles); Planet Mode (a world visibly evolves as you unlock reactions); online Tournament mode.
- **Chemistry mapping:** loose/fantasy — but the mechanic transplants directly to real chemistry: 2-item combination → real reactions; category completion → periodic families; final items → noble gases/stable products; hub elements → C, H, O.
- **Worth stealing:** discovery encyclopedia with % complete per category; no-penalty experimentation; milestone unlockables that can't be brute-forced; terminal-item marking; metered hint economy; goal-directed puzzle mode on the same engine; a world that visibly evolves with total discoveries.

## ChemCaper & physical chemistry games

- **ChemCaper: Act I — Petticles in Peril** (first "chemistry RPG," aimed at ages ~8–14, IGCSE ambitions):
  - Loop: explore a JRPG world → collect element orbs → brew potions at crafting stations → bond particles into "Petticles" (collectible creature companions = molecules) → Active Time Battles → story progress.
  - Chemistry mapping: each region = a periodic-table element; each creature = a molecule; Petticle creation teaches covalent/ionic/metallic bonding; potion brewing uses real glassware/separation techniques; a **"Chempendium" codex links every in-game fantasy object to its real-world chemistry**.
  - No classroom layer; mixed reviews (shallow as both game and teaching tool per some reviewers).
  - Steal: creatures-as-molecules collection; apparatus-as-crafting minigame; the fantasy→real codex pattern.
- **Elementeo** (battle card game): reduce opponent's electrons from 10–15 to 0. **Attack power = oxidation state; physical state determines board movement; electrons = hit points**; element cards combine into Compound cards; Alchemy wildcards (black holes, fusion). Personified cards encode real properties ("Oxygen Life Giver rusts metals," "Copper Cyclops shocks nearby cards").
- **Ion: A Compound Building Game** (Genius Games): simultaneous card-drafting; score only for *neutrally charged* compounds and noble-gas sets; expansions add transition metals, polyatomic ions, acids/bases. Charge balance is the entire point economy.
- **Covalence** (Genius Games): cooperative deduction — one "Knower" sees secret organic molecules and gives limited clue cards; "Builders" arrange element tiles to deduce structures. Asymmetric-information co-op.
- Also: **Valence** (build molecules, use acids/bases to attack), **Subatomic** (deck-builder: quarks → nucleons → atoms), **Periodic: A Game of the Elements** (move across a periodic-table board using trends as movement rules).
- **Periodic Table Battleship**: two laminated tables + folder screen; call shots by Period + Group ("Period 4, Group 7"), escalating to element name/symbol/atomic number/proton count. A J. Chem. Educ. variant ("Chemical Battleship") formalizes it. Steal: the table's own structure as a coordinate system; escalating call-out difficulty.

## Quiz/competition platforms (Kahoot, Blooket, Gimkit) + chemistry quiz apps

- **Kahoot:** synchronous quiz show — shared screen, timed MCQs, points for speed + accuracy, streaks, podium; team mode; async challenges. Lowest mechanical depth, best-researched.
- **Blooket:** **question sets decoupled from game modes** — one chemistry set plays through 25+ modes (Tower Defense, Gold Quest, Crypto Hack, Battle Royale…). Correct answers fuel each mode's mechanic. Meta: collectible "blooks" with rarity tiers bought via token boxes — gacha collection drives return play; solo modes for homework.
- **Gimkit:** **money economy** — each correct answer earns cash; students spend mid-game on upgrades (money-per-question, streak multiplier, insurance) so accuracy compounds. 10+ modes including 2D movement worlds (answer questions to earn energy to move), social-deduction Trust No One, and Creative mode where students build maps. KitCollab lets students contribute questions.
- **Chemistry quiz/flashcard apps:** Quizlet (Learn/Match/Test + **Quizlet Live team relay where the answer pool is split across teammates**); Brainscape (**confidence-based spaced repetition** — rate 1–5, low-confidence cards recur); Memrise-style SRS + mnemonic courses for element symbols.
- **Teacher features across the trio:** live host dashboards (per-question class accuracy in real time), assignable homework modes with completion reports, question-bank sharing.
- **Worth stealing:** decouple content from game shells — write chemistry content once, skin it many ways; Gimkit's spend-your-earnings upgrade economy; Blooket's collection meta; answer-fuels-movement; Quizlet Live's forced collaboration; confidence-based SRS.

## BrainPOP + Toca Lab: Elements + Tinybop (younger learners)

- **BrainPOP:** animated movies + quizzes + GameUp (curated games). Distinctive tooling: **SnapThought** — students screenshot gameplay moments and write reflections/predictions submitted to the teacher (metacognition bolted onto play); Make-a-Map concept mapping; Quiz Mixer (customize/share quizzes, teacher grades in-system); assignment + feedback loop via My Classes. Steal: the reflection-capture pattern that makes any game assessable.
- **Toca Lab: Elements** (ages ~6–10): the periodic table as a character collection. Each element is a creature with personality, texture, voice. Pick an element → subject it to lab tools (centrifuge, Bunsen burner, cooling agent, test tubes, oscilloscope) → it transforms into a new element → fills the table-as-collection-screen (discover all 118). No instructions, no fail states; accuracy intentionally loose — the goal is affection for the table. Steal: elements-as-characters; lab tools as toys; the table itself as the progress screen.
- **Tinybop States of Matter** (early elementary): open-ended sandbox — heat, cool, and manipulate matter; watch molecular behavior change across phases; interactive vocabulary labels in 30+ languages; no scores; teacher handbook. Steal: direct-manipulation molecular view; multilingual tap-to-label vocabulary.

## Minecraft Education — Chemistry Update

- **What it is:** chemistry feature set in Minecraft Education (toggleable in Bedrock): four crafting stations + an element/compound resource pack + a free Chemistry Lab Journal of lesson-ready recipes.
- **The four stations:**
  - **Element Constructor:** sliders for protons/neutrons/electrons → the element block whose counts you set. 118 elements + **400+ stable isotopes**; wrong counts yield unknown/unstable results. Atomic structure literally is the crafting recipe.
  - **Compound Creator:** place element counts in a grid (2 H + 1 O) → 30+ compounds (luminol, peroxide, polyethylene, soap, latex…). Stoichiometry = recipe correctness.
  - **Lab Table:** combine elements/compounds to run experiments producing usable items — e.g., water + sodium hypochlorite → bleach.
  - **Material Reducer:** place any Minecraft block → it decomposes into its constituent elements by percentage (reverse-engineer the world's composition).
- **Craftable products that matter in gameplay** (the key motivator — chemistry outputs are *useful*): helium balloons, glow sticks and sparklers (color depends on the element — calcium → orange), bleach, ice bombs, heat blocks, underwater torches and underwater TNT (magnesium), super fertilizer (ammonia), hardened/stained glass, medicine set (antidote, elixir, eye drops, tonic).
- **Loop:** gather/reduce materials → construct elements → combine into compounds → craft products → use them in survival/creative play or teacher-built lab worlds. Progression is intrinsic (capability unlocks), not XP.
- **Multiplayer:** full Minecraft multiplayer — shared worlds, co-op labs, teacher-hosted servers; Classroom Mode oversight (teleport, chat, pause).
- **Teacher features:** lesson plans + Chemistry Lab Journal (every recipe as a lab worksheet); pre-built chemistry worlds; in-game chalkboards/NPCs; **Camera + Portfolio/Book & Quill for student evidence capture and export**; O365 sign-in, school licensing.
- **Worth stealing:** chemistry outputs feeding a larger game economy — you make compounds because the products do things, not because a quiz asked; proton/neutron/electron sliders as element crafting; the Material Reducer decomposition mechanic; isotopes as first-class content; in-game evidence capture as assessment.
